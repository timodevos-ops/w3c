Onderzoek W3C

Waar staat de afkorting voor?

W3C = World Wide Web Consortium

Definitie

Het W3C is een organisatie die webstandaarden maakt. Opgericht in 1994 door Tim Berners-Lee. Ze maken regels voor HTML, CSS, etc. zodat websites in alle browsers goed werken.

Leg het concept uit in eigen woorden

Het W3C is als het ware het regelboek van het internet. Ze bepalen hoe websites moeten worden opgebouwd en vormgegeven. Zo zorgt het ervoor dat een website die in Chrome werkt, ook werkt in Firefox of Safari. Zonder het W3C zou elke browser websites anders weergeven.

Hoe draagt W3C bij aan de functionaliteit van het internet?

  • HTML & CSS standaarden (structuur en opmaak)
  • Toegankelijkheid (WCAG) voor mensen met beperkingen
  • Mobiele web standaarden
  • Semantisch web (data structureren)

Veiligheid

Rol bij beveiliging

Het W3C beheert geen netwerkprotocollen, maar heeft wel beveiligingsstandaarden:

  • CSP: voorkomt XSS-aanvallen
  • CORS: bepaalt hoe websites data van andere domeinen mogen ophalen
  • SRI: controleert of geladen bestanden niet zijn gewijzigd
  • WebAuthn: inloggen met vingerafdruk of gezichtsherkenning

Welke data zou gestolen kunnen worden?

  • Persoonlijke gegevens (naam, adres, e-mail)
  • Inloggegevens
  • Financiële gegevens
  • Sessie-tokens (cookies)
  • Browsing-gedrag

Hoe kunnen webontwikkelaars bijdragen?

  • Deelnemen aan werkgroepen (Working Groups)
  • Feedback geven op concepten via GitHub
  • Bug reports indienen
  • Tests schrijven
  • Deelnemen aan Community Groups

Hoe kunnen webontwikkelaars profiteren?

  • Consistente websites in alle browsers
  • Toegankelijkheid (WCAG)
  • Toekomstbestendigheid
  • Gratis documentatie
  • Innovatie (nieuwe standaarden)

Conclusie

Het W3C zorgt ervoor dat het web goed werkt voor iedereen door standaarden te maken. Webontwikkelaars kunnen bijdragen door feedback te geven en profiteren door standaarden te volgen.
