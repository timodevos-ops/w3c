# Zoekstrategie: Onderzoek naar W3C

## Onderwerp
W3C (World Wide Web Consortium)

## Zoektermen gebruikt
- "W3C" OR "World Wide Web Consortium"
- "W3C standards" OR "web standards"
- "W3C security" OR "W3C beveiliging"
- "W3C accessibility" OR "WCAG"
- "webontwikkelaars W3C" OR "developers W3C"
- "Tim Berners-Lee W3C"
- "CSP CORS SRI WebAuthn"

## Zoekmachines en bronnen
1. **Google** - Algemene zoekopdrachten
2. **W3C.org** - Officiële website van het W3C
3. **MDN Web Docs** - Documentatie over webstandaarden
4. **GitHub** - Open source repositories van W3C

## Beoordeling van bronnen
- **Betrouwbaarheid:** Officiële W3C-website (w3.org) als primaire bron
- **Actualiteit:** Gecontroleerd op recente informatie (2024-2025)
- **Relevantie:** Alleen bronnen over W3C en webstandaarden

## Gevonden bronnen
1. https://www.w3.org/ - Officiële website
2. https://www.w3.org/standards/ - Standaarden overzicht
3. https://www.w3.org/WAI/ - Web Accessibility Initiative
4. https://www.w3.org/TR/CSP/ - Content Security Policy
5. https://www.w3.org/TR/cors/ - Cross-Origin Resource Sharing
6. https://www.w3.org/TR/SRI/ - Subresource Integrity
7. https://www.w3.org/TR/webauthn/ - Web Authentication
8. https://www.w3.org/TR/WCAG21/ - WCAG 2.1
9. https://www.w3.org/People/Berners-Lee/ - Tim Berners-Lee
10. https://www.w3.org/community/ - Community Groups
11. https://web-platform-tests.org/ - Web Platform Tests

## Conclusie zoekstrategie
De zoekstrategie was effectief omdat de officiële W3C-website alle benodigde informatie bevat. De meeste antwoorden konden direct worden gevonden op w3.org. Aanvullende informatie werd gevonden via MDN Web Docs en GitHub.
